## 关于交个朋友 VPN

交个朋友 VPN 致力于提供清晰、易用的跨平台连接体验。你可以通过适配的客户端导入订阅，在支持的设备上管理和使用节点。

本仓库用于发布项目介绍、客户端指引、常见问题及公开更新信息。服务入口、账户和订阅相关操作请以官方网站展示的信息为准。

## 开始使用

1. 访问[交个朋友 VPN 官方网站](https://交个朋友.com)。
2. 根据网站页面提示了解服务及账户相关信息。
3. 按照设备类型选择兼容客户端。
4. 在账户页面获取订阅信息，并按客户端说明导入。
5. 连接前确认所选节点、客户端配置及本地网络环境。

请妥善保管账户凭据和订阅链接，不要将其公开发布或分享给他人。
