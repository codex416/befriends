# 常见问题

## 订阅导入失败怎么办？

1. 检查复制的订阅链接是否完整，前后是否带有空格。
2. 确认设备当前可以正常访问网络。
3. 在客户端中重新更新订阅。
4. 检查客户端版本及其订阅格式兼容性。
5. 仍无法解决时，通过官方网站查找当前支持入口。

## 更新订阅后没有节点怎么办？

请检查订阅是否已过期、账户状态是否正常，以及客户端是否提示更新失败。不要在公开渠道发送个人订阅链接。

## 节点连接失败怎么办？

可以依次尝试：

- 更换一个当前可用的节点。
- 重新启动客户端并更新订阅。
- 检查设备系统时间是否正确。
- 暂时切换网络环境，以判断是否为当前网络限制。
- 查看客户端日志中的错误提示。

不同网络环境和客户端版本可能导致不同表现，单次连接失败不一定代表节点长期不可用。

## 支持哪些地区？

项目节点地区包括香港、日本、美国和新加坡等。节点会根据服务情况调整，请以客户端实际显示为准。
