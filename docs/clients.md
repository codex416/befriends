# 客户端说明

交个朋友 VPN 支持通过兼容客户端导入订阅。请根据设备系统和个人使用习惯选择客户端。

## 支持的客户端类型

| 客户端 | 常见使用平台 | 说明 |
| --- | --- | --- |
| Clash 兼容客户端 | Windows、macOS、Android 等，具体取决于客户端 | 适合使用规则组和配置文件的用户 |
| Shadowrocket（小火箭） | iPhone、iPad | Apple 移动设备上的代理客户端 |
| NekoBox | Android | Android 平台客户端 |

> 以上为客户端类型说明，不代表每个客户端均支持所有操作系统。请以对应客户端的官方发布信息为准。

## 通用导入流程

1. 从可信的官方渠道安装对应客户端。
2. 登录交个朋友 VPN 官方网站。
3. 在账户或订阅页面获取个人订阅链接。
4. 在客户端中找到订阅导入、添加配置或从 URL 导入入口。
5. 粘贴个人订阅链接并保存。
6. 更新订阅，等待节点列表加载完成。
7. 选择可用节点后再发起连接。

客户端的菜单名称可能因版本和系统语言不同而变化。

## 安全提醒

- 订阅链接通常等同于账户访问凭据，请勿截图公开或转发给陌生人。
- 不要将个人订阅链接提交到 GitHub Issue、公开群组或第三方检测网站。
- 仅从可信来源下载客户端，留意仿冒应用。
- 如果订阅泄露，请尽快通过官方网站查找更新或重置订阅的方式。

## 故障排查

如果无法导入或更新订阅，请先检查网络连接、订阅链接是否完整，以及客户端是否支持当前订阅格式。更多排查步骤见[常见问题](faq.md)。
